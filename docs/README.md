# Portfolio website (GitHub Pages)

This folder is the source of the portfolio website. GitHub Pages serves it from the `/docs` folder of this repository.

Live site: https://karthiksasath-gif.github.io/cybersecurity-portfolio/

```
docs/
  index.html  style.css  script.js
  favicon/favicon.svg
  assets/images/    profile photo
  assets/projects/  project screenshots
  assets/resume/    resume PDF (public copy)
```

## Updating
- Resume: replace `assets/resume/Karthik_S_SOC_Analyst_Resume.pdf` with a file of the same name.
- New project: copy one `<article class="ticket">` block in `index.html` and edit the text and screenshot.
- Edit any file with the pencil icon on GitHub and commit; the site refreshes in about a minute.
